# 🐷 Celenganku

> Rencanakan tabunganmu dengan mudah

Aplikasi Android untuk membantu kamu merencanakan tabungan, menghitung kapan target tercapai, dan memvisualisasikan barang impianmu.

---

## ✨ Fitur

| Fitur | Deskripsi |
|---|---|
| 🎯 **Simulasi Target Tabungan** | Hitung estimasi waktu tabungan berdasarkan setoran harian/mingguan/bulanan |
| 📈 **Tantangan 52 Minggu** | Tantangan menabung naik bertahap selama 52 minggu |
| 🎁 **Barang Impian** | Upload foto barang impian + hitung setoran per bulan untuk membelinya |
| 💫 **Splash Screen** | Animasi loading dengan kalimat motivasi berjalan |

## 🛠️ Tech Stack

- **Language:** Java
- **Min SDK:** 24 (Android 7.0)
- **Target SDK:** 34 (Android 14)
- **UI Library:** Material Components for Android
- **Build System:** Gradle (Kotlin DSL)

## 🚀 Cara Install

### Download APK
Unduh APK terbaru dari halaman **[Releases](../../releases)**.

### Build dari Source
1. Clone repo ini:
   ```bash
   git clone https://github.com/USERNAME/Celenganku.git
   ```
2. Buka dengan **Android Studio**
3. Klik **Run ▶** atau build APK via `Build > Build Bundle(s) / APK(s) > Build APK(s)`
